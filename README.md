# SafeSteps — Your Digital Safety Guide

**Track 02: Women's Safety & Digital Inclusion**

SafeSteps is a digital safety guidance platform designed to help women and other internet users recognise common online risks, improve their privacy habits, and make more and more informed decisions online.

Rather than just filling users with technical information, here SafeSteps provides practical guidance through interactive learning and self-reviewing tools.

## The Problem

Online risks such as account phishing, account impersonation, unwanted messages, and privacy exposure can make navigating digital spaces difficult and unsafe.

People may not always know how to recognise warning signs, protect their accounts, or find reliable information when they need help.

## Our Solution

SafeSteps brings practical digital safety guidance together in one accessible platform.

### Features

- **Safety Assistant:** Guided steps for five main online safety situations.
- **Learning Hub:** Five short educational lessons covering digital safety topics.
- **Knowledge Check:** An interactive 10-question quiz.
- **Privacy Checkup:** A 15-point checklist for reviewing everyday privacy and security habits.
- **Support Resources:** Searchable links to official online safety and platform resources, including Sri Lankan resources as well.

## Privacy Approach

- No account registration is required.
- The application does not ask users to submit passwords or private conversations.
- Learning and checklist progress are stored locally in the browser.
- The Safety Assistant provides general educational guidance rather than automated threat detection.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/Nuwani45/SafeSteps.git
cd SafeSteps
npm install
npm run dev
```

Open the local URL provided by Vite.

### Production Build

```bash
npm run build
```

The production files are generated in the `dist` directory.

## Limitations

SafeSteps is an educational guidance tool. It is not an emergency service, legal service, professional support service, or automated security scanner. Its guidance is general, and its platform settings and reporting procedures may change .
